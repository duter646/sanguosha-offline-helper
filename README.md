# 三国杀一将成名线下辅助

面向线下三国杀玩家的纯前端辅助工具，用于查询武将技能、管理将池，并按照特殊武将的技能规则生成随机候选结果。

在线体验：<https://duter646.github.io/sanguosha-offline-helper/>

## 功能

- 首页提供常用特殊武将工具入口，并按使用次数排序；使用记录保存在浏览器本地。
- 武将查询支持按武将名、技能名和技能描述搜索。
- 武将查询采用分页展示，卡片显示武将基础信息和技能名，点击后可查看完整技能描述及官方资料链接。
- 将池支持新建、切换、全选、全不选、搜索和分页配置，配置保存在浏览器本地。
- 技能工具支持候选结果抽取、已获得结果记录和单个工具重置。
- 工具切换时会自动清理上一个工具的候选结果和临时状态，避免不同工具之间互相污染。
- 已针对许劭、张裕、神华佗、关宁、管宁、左慈、神曹丕、曹华、谋曹爽、神张角、乐蔡邕等特殊技能提供独立规则辅助。

部分工具不依赖将池，例如固定牌名、随机选项或牌堆相关的工具；这类工具不会显示将池配置入口。

## 快速开始

需要 Node.js 环境。安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

启动后按终端提示打开本地地址。

## 数据导入

项目内置官方武将页面索引。需要更新官方武将数据时执行：

```bash
npm run data:import
```

该命令需要网络访问官方武将网站：<https://x.sanguosha.com/hero/>。

导入脚本主要生成官方页面索引、技能文本和来源标记，不会覆盖人工维护的特殊技能规则。

## 构建与预览

```bash
npm run build
npm run preview
```

构建前会执行 TypeScript 类型检查。Vite 使用相对资源路径，部署到 GitHub Pages 的仓库子路径时也能正常加载。

## GitHub Pages 部署

项目已配置 GitHub Actions：`.github/workflows/deploy.yml`。

推送到 `main` 分支后，工作流会自动执行依赖安装、构建和 Pages 发布。首次使用时，需要在仓库设置中完成：

`Settings → Pages → Build and deployment → Source → GitHub Actions`

也可以在 GitHub Actions 页面手动运行 `Deploy to GitHub Pages`。

## 项目结构

```text
src/
├─ app/       页面与交互逻辑
├─ data/      官方武将索引和人工维护数据
├─ domain/    武将、将池和技能规则模型
├─ stores/    浏览器本地存储
└─ styles/    全局样式
scripts/      官方数据导入脚本
.github/      GitHub Actions 工作流
```

## 数据与规则说明

官方技能文本和武将资料以三国杀官方武将网站为准。线下辅助规则由项目中的领域规则实现，实际游戏结算仍应以当前使用的实体牌、武将版本和桌面规则为准。
